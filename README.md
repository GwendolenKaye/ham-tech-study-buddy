# Ham Tech Study Buddy

A phone-friendly study app for the FCC Technician ham license. It has picture labs for the electrical ideas, and eleven one-page cheat sheets you can print.

## Sheets

Formulas, electrical ideas, rules and frequencies, operating, propagation, the station, parts and symbols, gear, modes and satellites, antennas, and safety.

The print packet is `public/sheets/ham-tech-cheat-sheets.pdf`. The same pages, as a print layout, are `public/sheets/packet.html`.

## Put it on your phone

This has to be opened as its own site, not inside a chat preview. Chat previews block saving and printing.

After the site is on a real web address:

- iPhone: open it in Safari, tap Share, then Add to Home Screen.
- Android: open it in Chrome, then Install app.

Then open **Sheets** and tap **Open the print packet**. Use the phone’s share or print button. That is the copy that actually prints.
