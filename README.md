# Ham Tech Study Buddy

A phone-friendly study app for the FCC Technician ham license. It has picture labs for the electrical ideas, and eleven one-page cheat sheets you can print.

Repository: https://github.com/GwendolenKaye/ham-tech-study-buddy

## Print from your phone

The chat preview cannot save or print. This repository publishes a small phone site that can.

1. On GitHub, open **Settings → Pages**.
2. Under **Build and deployment**, choose **GitHub Actions**.
3. After the action goes green, open https://gwendolenkaye.github.io/ham-tech-study-buddy/
4. iPhone: Safari → Share → Add to Home Screen. Android: Chrome → Install app.
5. Tap **Open the print packet**, then use the phone’s share button and choose Print.

The PDF in the repo is `public/sheets/ham-tech-cheat-sheets.pdf`.
